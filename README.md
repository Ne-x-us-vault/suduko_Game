# Gridline Sudoku

A clean, polished Sudoku game built with Flutter.

## Features

- **4 difficulty levels** — Easy, Medium, Hard, Expert
- **Puzzle generation** — unique-solution backtracking algorithm
- **Notes mode** — pencil in candidate numbers per cell
- **Undo** — full move history with undo support
- **Hints** — 3 per game, reveals a correct cell from the solution
- **Timer** — tracks your solve time
- **Error highlighting** — wrong entries shown in red
- **Number pad** — shows remaining count per digit
- **Progress bar** — visual completion indicator
- **Win dialog** — celebrates completion with stats
- **Light & dark themes** — follows system preference

## Getting started

```bash
flutter pub get
flutter run
```

For web:

```bash
flutter run -d chrome
```

## How it works

Puzzles are generated by filling a complete valid board, then removing cells one at a time while verifying the puzzle retains a unique solution. Difficulty controls how many cells are removed (Easy: 43 clues, Medium: 38, Hard: 33, Expert: 22).

## Tech stack

- Material 3 with custom theme
