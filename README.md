# Gridline Sudoku

A clean, polished Sudoku game built with Flutter — ink-on-paper design with a single indigo accent.

## Features

- **4 difficulty levels** — Easy (38 clues), Medium (30), Hard (25), Expert (22)
- **Puzzle generation** — unique-solution backtracking algorithm
- **Notes mode** — pencil in candidate numbers per cell
- **Auto note-clearing** — placing a number removes it as a candidate from peer cells' notes
- **Undo** — full move history with undo support
- **Hints** — 3 per game, reveals a correct cell from the solution
- **Timer** — pauses automatically when the app is backgrounded
- **Error highlighting** — wrong entries flagged in red with a shake + haptic
- **Keyboard support** — type 1–9, arrow-key navigation, N for notes, Z for undo, H for hints
- **Number pad** — shows remaining count per digit, red when scarce
- **Progress bar** — visual completion indicator
- **Live stats** — games played, won, win rate and best streak, persisted locally
- **Best times** — recorded per difficulty
- **Win dialog** — animated trophy, time, "new best" badge, errors/hints summary
- **Exit guard** — confirms before abandoning an in-progress puzzle
- **Light & dark themes** — follows system preference

## How it works

Puzzles are generated by filling a complete valid board, then removing cells one at a time while verifying the puzzle retains a unique solution. Difficulty controls how many cells are removed (Easy: 38 clues, Medium: 30, Hard: 25, Expert: 22).
